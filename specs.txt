VUE D'ENSEMBLE
--------------
Application web de cartographie interactive pour la Terre du Milieu (jeu de rôle).
Architecture modulaire JavaScript avec backend Flask/Python et base SQLite.
Authentification Google OAuth pour sauvegarde cloud synchronisée.

ARCHITECTURE GLOBALE
--------------------

Frontend:
- HTML5 + CSS3 (Tailwind CDN) + Vanilla JavaScript (ES6 modules)
- Architecture modulaire avec pattern Manager
- Responsive design (desktop + mobile)
- Navigation tactile et souris

Backend:
- Flask (Python 3.x)
- SQLite pour persistance
- Google OAuth 2.0
- API REST pour sync cloud

CONVENTIONS DE CODAGE JAVASCRIPT
---------------------------------

1. STRUCTURE DES MANAGERS:
   - Un fichier = un Manager
   - Export par défaut: export default class NomManager
   - Pattern singleton via window.nomManager
   - Constructor avec injection de dépendances

2. NAMING CONVENTIONS:
   - Classes: PascalCase (DataManager, FilterManager)
   - Fichiers: kebab-case (data-manager.js)
   - Méthodes: camelCase (loadData, applyFilters)
   - Constantes: UPPER_SNAKE_CASE (MAP_WIDTH, MAX_SCALE)
   - Variables globales: camelCase avec window. prefix

3. ORGANISATION DES MÉTHODES:
   class ExampleManager {
       constructor(dependencies, config) { }  // Injection dépendances
       
       init() { }                             // Initialisation
       
       // Méthodes publiques
       publicMethod() { }
       
       // Méthodes privées (préfixe _)
       _privateMethod() { }
       
       // Event handlers
       handleEvent(e) { }
       
       // Getters/Setters
       getData() { }
       setData(data) { }
   }

4. GESTION DES ÉVÉNEMENTS:
   - Listeners dans init() ou setup methods
   - Cleanup explicite si nécessaire
   - Delegation pour éléments dynamiques
   - Arrow functions pour conserver context

5. IMPORTS/EXPORTS:
   // constants.js
   export const CONSTANT_NAME = value;
   
   // manager.js
   import { CONSTANT } from '../utils/constants.js';
   export default class Manager { }

6. LOGGING:
   - Console.log avec emojis pour catégorisation:
     🚀 Initialisation
     ✅ Succès
     ❌ Erreur
     ⚠️  Warning
     📍 Position/Navigation
     🗺️  Carte
     🔍 Zoom/Filtres
     📱 Mobile/Touch

FONCTIONNALITÉS PRINCIPALES
----------------------------

1. GESTION MULTI-CARTES (v1.1.4):
   - Ajout/suppression de cartes personnalisées
   - Upload d'images (auto-resize à 5000px largeur)
   - Configuration échelle par carte (miles/largeur)
   - Basculement entre cartes actives
   - Filtres et données par carte (mapId)
   - Stockage: settings dans localStorage + cloud

2. NAVIGATION CARTE:
   - Pan (drag souris ou 2 doigts tactile)
   - Zoom (molette, pinch, slider UI)
   - Reset view (bouton home)
   - Contraintes viewport (bounds)
   - Scale range: 0.1 (10%) à 4.0 (400%)
   - Transform: CSS translate + scale

3. LIEUX (Locations):
   - Placement manuel (clic + modal)
   - Drag & drop repositionnement
   - Propriétés: nom, description, couleur, images
   - États: connu/inconnu, visité/non-visité
   - Vignettes 64x64px (affichées si zoom > 50%)
   - Affichage cercle coloré (zoom < 50%)
   - Association à une carte (mapId)

4. RÉGIONS (Regions):
   - Tracé polygonal (multi-points)
   - Clic droit pour terminer
   - Propriétés: nom, description, couleur
   - Opacité ajustable (slider)
   - Rendering SVG overlay
   - Association à une carte (mapId)

5. VOYAGES (Paths):
   - Tracé ligne brisée
   - Calcul distances (miles)
   - Segmentation journalière
   - Détection régions traversées
   - Détection lieux proximité (50px)
   - Génération descriptions IA (Gemini)
   - Modale segments jour par jour

6. FILTRES:
   - Par couleur (locations + regions)
   - Par statut (connu/inconnu, visité/non-visité)
   - Visibilité lieux/régions
   - Opacité régions (slider 0-100%)
   - Sauvegarde par carte (localStorage)

7. POSITION AVENTURIERS:
   - Marqueur draggable Position.png
   - Stockage coordonnées (x, y)
   - Redimensionnement auto selon zoom
   - Sync cloud

8. CALENDRIER:
   - Date courante (jour/mois Terre du Milieu)
   - Saisons avec symboles (🌱☀️🍂❄️)
   - Indicateur UI cliquable

9. JOURNAL DE VOYAGE:
   - Stockage descriptions générées
   - Organisation par voyage
   - Export/consultation historique

10. AUTHENTIFICATION & SYNC:
    - Google OAuth 2.0
    - Sauvegarde auto (2s delay)
    - Détection conflits (timestamp)
    - Résolution manuelle
    - Indicateur statut cloud (icône)

11. IMPORT/EXPORT:
    - Format JSON unifié
    - Export complet données
    - Import avec merge
    - Upload images multiples
    - Bibliothèque images utilisateur

12. PERSONNAGES (v1.1.5):
    - Gestion liste personnages aventure
    - Types: PJ (Personnage Joueur) / PNJ
    - Propriétés: nom, description, images (principale/vignette)
    - InfoBox partagée avec lieux/régions
    - Création/modification/suppression
    - Vignettes conditionnelles (type)
    - Sync cloud

STRUCTURE DONNÉES
-----------------

localStorage keys:
- middleEarthLocations: { locations: [...] }
- middleEarthRegions: { regions: [...] }
- middleEarthCharacters: { characters: [...] }
- availableMaps: [{ id, name, url, scale, width, height }]
- activeMapUrl: string
- currentCalendarDate: { day, month, season }
- adventurers_position: { x, y }
- filtersByMap: { [mapId]: { colors, visited, known } }

Cloud (SQLite):
- users: id, google_id, email, name
- travel_contexts: id, user_id, name, data_json
- api_usage: id, user_id, endpoint, tokens_used

Format Location:
{
  id: number,
  name: string,
  description: string,
  color: string,
  coordinates: { x: number, y: number },
  images: [{ url, type, isDefault }],
  known: boolean,
  visited: boolean,
  mapId: string | undefined,
  Rumeurs: string[],
  Tradition_Ancienne: string,
  evenements_voyage: object[]
}

Format Region:
{
  id: number,
  name: string,
  description: string,
  color: string,
  points: [{ x, y }],
  images: [],
  known: boolean,
  visited: boolean,
  mapId: string | undefined,
  type: "region"
}

Format Character:
{
  id: number,
  name: string,
  description: string,
  type: "PJ" | "PNJ",
  images: [{ url, type }]
}

API ENDPOINTS
-------------

GET  /api/auth/user              # Info utilisateur connecté
GET  /api/user/data              # Récupération données cloud
PUT  /api/user/data              # Sauvegarde données cloud
POST /api/upload/image           # Upload image
GET  /api/images/library         # Liste images utilisateur
POST /api/gemini/generate        # Génération texte IA

RÈGLES MÉTIER
-------------

1. ÉCHELLE CARTES:
   - Configurable par carte (défaut 600 miles)
   - Calculs distances: (pixels / MAP_WIDTH) * MAP_DISTANCE_MILES

2. FILTRES PAR CARTE:
   - Chaque carte a ses propres filtres
   - Auto-load au changement carte
   - Fallback filtres par défaut

3. SYNCHRONISATION:
   - Auto-save 2s après modification
   - Détection conflits par timestamp
   - Merge intelligent import/export

4. RESPONSIVENESS:
   - Breakpoint mobile: 768px
   - Touch events séparés souris
   - UI adaptative (toolbar bottom mobile)

5. PERFORMANCES:
   - Vignettes conditionnelles (zoom > 50%)
   - Lazy rendering régions
   - Debounce sync/filters

PROBLÈMES RÉSOLUS
-----------------

1. Import JSON sur tablette (v1.1.4):
   - Problème: Fichiers .json grisés dans l'interface de sélection mobile
   - Cause: Attribut accept=".json" trop restrictif pour certains navigateurs mobiles
   - Solution: accept=".json,application/json" (extension + type MIME)
   - Fichier concerné: index.html (input#import-file-input)
