Bonjour ! Je travaille sur une application de cartographie interactive pour la Terre du Milieu (jeu de rôle) basée sur Flask + JavaScript. L'application permet de naviguer sur une carte, tracer des chemins de voyage, gérer des lieux et régions, et générer des descriptions avec l'API Gemini.

Architecture actuelle :

Backend : Flask (app.py) avec base SQLite pour auth Google et contextes
Frontend : Structure modulaire avec plusieurs fichiers .js dans /js/managers/
Fichier principal : js/main.js (actuellement ~800 lignes, objectif : le garder concis)
Managers existants :

DataManager : gestion des données (lieux/régions)
FilterManager : filtres d'affichage
VoyageManager : gestion des segments de voyage
PathManager : tracé de chemins sur la carte
GeminiManager : génération de contenu IA
CalendarManager : gestion des saisons/calendrier
