Je travaille sur une application de cartographie interactive pour la Terre du Milieu (jeu de rôle) basée sur Flask + JavaScript. L'application utilise une architecture modulaire avec des managers spécialisés dans /js/managers/.

Architecture actuelle :

Backend : Flask (app.py) avec SQLite et routes API /api/auth/* et /api/contexts/*
Frontend : Structure modulaire avec managers séparés
Authentification : Infrastructure Google OAuth déjà en place côté serveur
Base de données : SQLite avec tables users, travel_contexts, api_usage
Managers existants :

DataManager : gestion des données (lieux/régions)
FilterManager : filtres d'affichage
VoyageManager : gestion des segments de voyage
PathManager : tracé de chemins sur la carte
GeminiManager : génération de contenu IA
CalendarManager : gestion des saisons/calendrier
SettingsManager : paramètres utilisateur
Infrastructure backend disponible :

Routes /api/auth/user, /api/auth/google, /api/auth/google/callback
Routes /api/contexts (GET/POST), /api/contexts/<id> (GET/PUT)
Routes /api/user/data (GET/PUT) pour données personnalisées
Google OAuth configuré avec variables d'environnement
OBJECTIF : Créer/compléter AuthManager dans /js/managers/auth-manager.js et l'intégrer dans main.js.

Fonctionnalités à implémenter :

Authentification Google OAuth

Vérification du statut d'authentification au démarrage
Redirection vers /auth/google pour connexion
Mise à jour de l'interface utilisateur (photo de profil, nom)
Gestion des erreurs d'authentification
Sauvegarde des contextes utilisateur

Modal de sauvegarde avec nom du contexte
Envoi vers /api/contexts (POST)
Liste des contextes sauvegardés depuis /api/contexts (GET)
Chargement d'un contexte via /api/contexts/<id> (GET)
Suppression de contextes
Synchronisation automatique des données

Auto-sync des données utilisateur vers /api/user/data (PUT)
Chargement automatique depuis /api/user/data (GET) à la connexion
Debounce des modifications (2 secondes)
Synchronisation des lieux/régions/tracés/saisons/calendrier
